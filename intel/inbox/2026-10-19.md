## Idle compaction in the terminal

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.299
- What changed: A conversation of 200K tokens or more that sits idle for about 54 minutes is now compacted before its one-hour prompt cache expires. `"idleCompaction": false` in settings.json turns it off, and 2.1.302 added an `Idle compaction` row to `/config`.
- Touches: R-SESS-007, templates/project/.claude/settings.json
- Action: pool-tip
- Why: R-SESS-007 tells agents not to rely on compaction, and a project left idle can now compact without being asked, so the director should know the switch exists.

## Hook `updatedInput` is validated

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.300
- What changed: `updatedInput` returned by PreToolUse and PermissionRequest hooks is now checked like Claude's own tool input: unknown keys are dropped, and input the tool rejects denies the call.
- Touches: plugins/sdlc-core/hooks/hooks.json, plugins/sdlc-core/scripts/guard-heavy-files.sh
- Action: none
- Why: The factory's hooks only allow or block a call and never rewrite its input, so nothing breaks.

## Prompt and agent hooks run at most 12 at a time

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.302
- What changed: At most 12 prompt or agent hooks of one event run at once; the rest wait their turn. Fork subagents are also on by default in `claude -p`, the Agent SDK, the desktop app and VS Code.
- Touches: plugins/sdlc-core/hooks/hooks.json, plugins/sdlc-lean/agents
- Action: none
- Why: sdlc-core uses command hooks, not prompt or agent hooks, and the lean roles name their sub-agents explicitly.

## Fast mode for Opus 5.5 is generally available

- Source: https://platform.claude.com/docs/en/release-notes/overview
- Published: 2026-10-15
- What changed: Fast mode for Claude Opus 5.5 is out of research preview and no longer needs the `fast-mode-2026-02-01` beta header; Opus 5 and 4.8 keep the header requirement.
- Touches: evals/budget.json, plugins/sdlc-lean/agents/reviewer.md
- Action: none
- Why: The factory sets no fast-mode option, and the director decides whether to turn it on.
