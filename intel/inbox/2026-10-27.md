## Hooks that failed open on Windows

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.309
- What changed: PreToolUse and PermissionRequest hooks written for PowerShell, or with a command made only of quoted strings, let the tool call through when Git Bash was missing; 2.1.309 and 2.1.310 fixed this, and PowerShell hooks that exit with code 2 now block.
- Touches: plugins/sdlc-core/hooks/hooks.json, .claude/hooks/guard-main.sh, registry/pool.md
- Action: pool-tip
- Why: It is a second reason, beside P146, to keep every machine on a current Claude Code version, because a guard hook that fails open guards nothing.

## SubagentStop hooks ran too often

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.311
- What changed: `SubagentStop` hooks ran about twice a minute for each running subagent instead of once when it finished; this is fixed.
- Touches: plugins/sdlc-core/hooks/hooks.json
- Action: audit-trigger
- Why: If sdlc-core hooks on `SubagentStop`, the next audit should check its counters and handoff checks for double counts from versions before 2.1.311.

## Compaction changes

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.311
- What changed: Standard-context sessions that run past 200K tokens now compact and continue instead of stopping; compaction asks once more for a summary when the first reply had none; and `DISABLE_COMPACT` in settings files can only turn compaction off.
- Touches: R-SESS-007, templates/project/.claude/settings.json
- Action: none
- Why: R-SESS-007 already tells agents to carry state in files rather than rely on compaction, and these changes make compaction safer without changing that advice.

- Source: https://platform.claude.com/docs/en/release-notes/overview
- Published: 2026-10-21
- What changed: API version `2026-10-21` is out, and the Python, TypeScript, C#, Go, Java, PHP, Ruby and `ant` CLI majors send it by default; they carry breaking changes.
