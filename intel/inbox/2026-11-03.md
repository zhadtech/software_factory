## Block writes outside the working directories

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.314
- What changed: The new setting `permissions.blockWritesOutsideWorkingDirectories` makes Write, Edit and NotebookEdit refuse paths outside the working directories in every permission mode.
- Touches: templates/project/.claude/settings.json
- Action: pool-tip
- Why: It is a cheap guard against an agent editing files in another project, which F11 forbids for the factory.

## Hooks on Bash now also see Monitor commands

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.314
- What changed: Hooks that match Bash now run on shell commands started by the Monitor tool; they can block or ask but not approve or rewrite. Hook `if` conditions such as `Monitor(tail *)` match like `Bash(tail *)`.
- Touches: .claude/hooks/guard-main.sh, .claude/settings.json
- Action: pool-tip
- Why: The main-branch guard now also covers commands run through Monitor, which closes a possible gap.

## Subagent effort and model changes

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.316, 2.1.317
- What changed: `CLAUDE_CODE_SUBAGENT_EFFORT` sets the effort subagents run at when nothing else names one, and a subagent on a different model from the main conversation now uses that model's saved or default effort instead of the session's.
- Touches: plugins/sdlc-lean/agents/product.md, plugins/sdlc-lean/agents/architect.md, plugins/sdlc-lean/agents/builder.md, plugins/sdlc-lean/agents/reviewer.md, plugins/sdlc-lean/agents/release.md
- Action: audit-trigger
- Why: The next audit should confirm that the `effort:` line in each role's frontmatter still takes effect, since the lean roles depend on it.

## Read tool stub removed

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.317
