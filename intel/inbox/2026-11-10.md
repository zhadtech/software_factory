## Bash permission-check bypasses fixed

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.319, 2.1.321
- What changed: Claude Code fixed a bypass where a crafted environment prefix hid part of a Bash command from permission checks, a `sed` case that skipped the check in accept-edits and auto mode, and deny rules not applying to the file that `cp` or `mv` into a directory writes.
- Touches: .claude/hooks/guard-main.sh, .claude/settings.json, templates/project/.claude/settings.json
- Action: audit-trigger
- Why: The next audit should confirm that the main-branch guard and the template's deny rules still catch a command written with an environment prefix, and that every machine runs 2.1.321 or later (P148).

## Deny instead of prompting

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.319
- What changed: The new setting `permissions.denyInsteadOfPrompting` denies a tool call that would wait on a permission prompt and lets the turn continue, in terminal sessions, subagents and teammates.
- Touches: templates/project/.claude/settings.json
- Action: pool-tip
- Why: A scheduled or unattended run that stops at a prompt waits forever, so this setting could make it fail fast and report.
