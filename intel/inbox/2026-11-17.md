## Permission and Bash deny-rule gaps fixed

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.323
- What changed: Relative deny and ask rules such as `Read(./.env)` stopped covering the project after a `cd`; some deny and ask rules did not apply to certain Bash commands; some compound Bash commands ran without asking; and a Bash allow rule could run a different program than it names. All are fixed.
- Touches: .claude/hooks/guard-main.sh, templates/project/.claude/settings.json
- Action: audit-trigger
- Why: The next audit should confirm the main-branch guard and the template's deny rules were tested against these cases, and that every machine runs 2.1.323 or later.

## Scheduled tasks ask before running skills with hooks

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.323
- What changed: Scheduled tasks and `/loop` now ask before running a skill that declares `allowed-tools` or hooks; `Skill(name)` in `permissions.allow` lets it run unattended.
- Touches: intel/scout.md, plugins/sdlc-core
- Action: pool-tip
- Why: The scout and the audit run unattended, so a skill with hooks would stall them without that allow rule.

## Plugins can state a Claude Code version range

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.323
- What changed: `plugin.json` accepts `engines["claude-code"]`; plugins outside their range are not installed, updated or loaded, and install picks the newest version that fits.
- Touches: plugins/sdlc-core/.claude-plugin/plugin.json, plugins/sdlc-lean/.claude-plugin/plugin.json, plugins/sdlc-stacks/.claude-plugin/plugin.json
- Action: pool-tip
- Why: The factory's hooks rely on recent Claude Code behavior (P146, P148), and a range would keep old machines from loading them half-working.

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
