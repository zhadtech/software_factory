## Code Mode skips a failing PreToolUse hook unless told to block

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.329
- What changed: In Code Mode, a `PreToolUse` hook that errors no longer refuses a script's tool call; set `"onFailure": "block"` on a hook that must refuse. Version 2.1.328 added the same setting for `mcp_tool` hooks.
- Touches: plugins/sdlc-core/hooks/hooks.json, .claude/hooks/guard-main.sh, registry/pool.md
- Action: pool-tip
- Why: The factory's guards are `PreToolUse` hooks, and a guard that crashes should stop the call rather than let it through.

## Stop and SubagentStop hooks now see the last reply in Claude Desktop

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.331
- What changed: Stop hooks that read the transcript sometimes missed the last reply in Claude Desktop; SubagentStop hooks now wait for it too.
- Touches: plugins/sdlc-core/scripts/check-handoff.sh, plugins/sdlc-core/hooks/hooks.json
- Action: audit-trigger
- Why: The handoff check reads a subagent's final reply, so the next audit should confirm it has no workaround for the old missing reply.

## Plugin manifests accept optionalDependencies

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.331
- What changed: A plugin can list `optionalDependencies`: plugins that install with it and can be disabled or uninstalled on their own. A partial plugin folder left by an interrupted update is also fixed.
- Touches: plugins/sdlc-core/.claude-plugin/plugin.json, plugins/sdlc-lean/.claude-plugin/plugin.json, plugins/sdlc-stacks/.claude-plugin/plugin.json
- Action: pool-tip
- Why: It is a way to install the three factory plugins together while keeping each removable, which the director may want to weigh.

## Managed marketplaces will auto-update by default

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.331
- What changed: On or after 2026-11-30, marketplaces in managed `extraKnownMarketplaces` update automatically unless the entry sets `"autoUpdate": false`.
- Touches: .claude-plugin/marketplace.json, templates/project/.claude/settings.json
- Action: none
- Why: The template does not set `extraKnownMarketplaces`, and projects already receive a plugin change only when its version changes (F9).

## Scheduled tasks and /loop last up to 30 days

- Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- Published: 2.1.330
- What changed: Recurring scheduled tasks and `/loop` run up to 30 days instead of 7 while their session keeps running; tasks saved by earlier versions may need scheduling again (2.1.329).
- Touches: intel/scout.md, audits/auditor.md
- Action: none
- Why: The scout and the audit run as routines that start fresh sessions, so the limit does not affect them.
