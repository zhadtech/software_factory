without opening anything else. Keep the "Open it when" column concrete — it is
the column that saves the tokens.

## Structure

| Path | What it is | Open it when |
|---|---|---|
| `src/` | application code | — (see rows below) |
| `src/routes/` | HTTP handlers, one file per resource | adding/changing an endpoint |
| `src/lib/` | shared pure helpers, no I/O | reusing logic; check here **before** writing a new helper |
| `tests/` | test suite, mirrors `src/` layout | after any behavior change |
| `config/` | env parsing + defaults | adding a setting; never hardcode |
| `scripts/` | one-off dev/ops scripts | rarely; not imported by app code |
